| Папка | Кейс (вкладка на сайте) |
|---|---|
| `santehnika/` | Сантехника |
| `roomlogic/` | Товары для дома (Roomlogic) |
| `suhofrukty/` | Продукты питания (сухофрукты и орехи) |
| `tehnika/` | Тяжёлая техника |

## Как называть файлы — важно

Галерея на сайте сама находит фото по имени: **`1.jpg`, `2.jpg`, `3.jpg`...**
подряд, без пропусков, начиная с `1`. Формат — обязательно **JPG**.

- Один файл `1.jpg` → фото покажется одно, без стрелок/точек.
- Несколько файлов подряд (`1.jpg`, `2.jpg`, `3.jpg`...) → появится галерея
  со стрелками и точками-индикаторами, можно листать туда-сюда (и свайпом
  на телефоне).
- Если назвать `2.jpg`, пропустив `1.jpg` — второе фото и всё, что после
  разрыва, сайт не найдёт. Нумерация должна идти подряд без дырок.
- PNG/WEBP и другие расширения пока не поддерживаются — конвертируйте в JPG.

Больше ничего прописывать в коде не нужно — просто закиньте файлы с
правильными именами в нужную папку, сайт подхватит их сам при следующей
загрузке страницы.
