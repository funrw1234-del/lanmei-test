# Настройка отправки заявок с сайта (почта + Telegram)

Код готов и лежит в проекте, на сайте сейчас две формы:
- **Бриф** (`#leadForm`, секция «Рассчитать доставку»)
- **Обратный звонок** (модалка, открывается кнопкой «Заказать звонок» в шапке)

Обе шлют в один и тот же Telegram-канал и на одну и ту же почту — но каждой
нужен **свой** EmailJS-шаблон (в письме от звонка не должно быть пустых строк
«Категория товара:», «Объём закупок:» и т.д., которых в этой форме просто нет).

Нужно завести 3 бесплатных сервиса и вписать 5 значений в `js/forms-config.js`.
Это шаги, которые может сделать только владелец аккаунтов — я не могу
создавать их за вас.

`emailjs.publicKey`, `emailjs.serviceId`, `emailjs.templateId` (бриф),
`emailjs.templateIdCallback` (звонок), `telegramWorkerUrl`.

## 2. EmailJS (доставка на почту)

1. Зарегистрируйтесь на [emailjs.com](https://www.emailjs.com/) — бесплатный тариф
   (200 писем/месяц) достаточно для старта.
2. **Email Services** → Add New Service → подключите свою почту (Gmail/Yandex/другой SMTP).
   После подключения скопируйте **Service ID**. — ✅ уже сделано.
3. **Email Templates** → Create New Template — шаблон для **брифа**. Тело письма:
   ```
   Новая заявка: {{formType}}

   Имя: {{name}}
   Телефон/Telegram: {{phone}}
   Категория товара: {{sku}}
   Объём закупок: {{budget}}
   Текущая схема: {{scheme}}
   Комментарий: {{msg}}
   ```
   Укажите получателя (**To Email**), сохраните, скопируйте **Template ID**. — ✅ уже сделано.
4. Ещё раз **Email Templates** → Create New Template — **второй** шаблон,
   для **обратного звонка**. Тело письма:
   ```
   Обратный звонок с сайта: {{formType}}

   Имя: {{name}}
   Телефон: {{phone}}
   ```
   Тот же **To Email**, что и в первом шаблоне. Сохраните и скопируйте **Template ID**
   — это и есть `templateIdCallback`.
5. **Account → General** — **Public Key**. — ✅ уже сделано (общий для всех шаблонов).

## 4. Вписать в код сайта

Откройте `js/forms-config.js` — там уже всё заполнено, кроме одного значения:

```js
templateIdCallback: 'ЗАМЕНИТЕ_НА_TEMPLATE_ID_ЗВОНКА' // ← сюда Template ID из шага 2.4
```

Пришлите этот ID мне — впишу и запушу.

---

## 5. Проверка

Откройте сайт → кнопка «Заказать звонок» в шапке → заполните телефон →
отправьте. Проверьте письмо и Telegram-канал. Если что-то не дошло —
консоль браузера (F12 → Console) покажет `console.warn` с причиной.
