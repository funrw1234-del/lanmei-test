# Настройка отправки заявок с сайта (почта + Telegram)

Код уже готов и лежит в проекте. Осталось завести 3 бесплатных сервиса и
вписать их ID в `js/forms-config.js`. Это шаги, которые может сделать
только владелец аккаунтов — я не могу создавать их за вас.

Итого нужно получить 4 значения для `js/forms-config.js`:
`emailjs.publicKey`, `emailjs.serviceId`, `emailjs.templateId`, `telegramWorkerUrl`.

---

## 1. Telegram-бот и канал/группа

1. В Telegram напишите **@BotFather** → `/newbot` → придумайте имя и username бота.
   BotFather пришлёт **токен бота** (строка вида `123456:AAExxxxx...`) — сохраните его,
   он понадобится на шаге 3 (в Cloudflare, не в коде сайта).
2. Добавьте бота **администратором** в ваш канал или группу, куда должны падать заявки.
3. Узнайте **chat_id** канала/группы:
   - Проще всего: перешлите (forward) любое сообщение из канала боту **@userinfobot** —
     он покажет ID пересланного чата (для каналов это отрицательное число вида `-1001234567890`).
   - Или: отправьте любое сообщение в канал, затем откройте в браузере
     `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` в ответе.

Сохраните токен и chat_id — они пойдут в Cloudflare на шаге 3, **не в код сайта**.

---

## 2. EmailJS (доставка на почту)

1. Зарегистрируйтесь на [emailjs.com](https://www.emailjs.com/) — бесплатный тариф
   (200 писем/месяц) достаточно для старта.
2. **Email Services** → Add New Service → подключите свою почту (Gmail/Yandex/другой SMTP).
   После подключения скопируйте **Service ID**.
3. **Email Templates** → Create New Template. Тело письма можно сделать так:
   ```
   Новая заявка: {{formType}}

   Имя: {{name}}
   Телефон/Telegram: {{phone}}
   Категория товара: {{sku}}
   Объём закупок: {{budget}}
   Текущая схема: {{scheme}}
   Комментарий: {{msg}}
   ```
   В настройках шаблона укажите получателя (**To Email**) — куда должны падать заявки.
   Сохраните и скопируйте **Template ID**.
4. **Account → General** — скопируйте **Public Key**.

---

## 3. Cloudflare Worker (релей в Telegram)

Токен бота нельзя класть в код сайта (его увидит любой через "просмотр кода страницы").
Поэтому запросы идут через маленький прокси-сервер на Cloudflare — токен хранится
только там.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/) (бесплатно).
2. В боковом меню: **Workers & Pages** → **Create** → **Create Worker**.
   Дайте имя, например `lanmei-forms`, нажмите **Deploy** (сначала задеплоится шаблон-заглушка).
3. Нажмите **Edit code** — откроется редактор. Удалите всё содержимое и вставьте
   код из файла [`cloudflare-worker/telegram-relay.js`](cloudflare-worker/telegram-relay.js)
   этого проекта. Нажмите **Deploy**.
4. **Settings → Variables and Secrets** у этого Worker'а → добавьте два секрета
   (тип **Secret**, не обычная переменная):
   - `TELEGRAM_BOT_TOKEN` — токен бота с шага 1
   - `TELEGRAM_CHAT_ID` — chat_id канала/группы с шага 1
5. Скопируйте адрес Worker'а — он вида `https://lanmei-forms.ВАШ-АККАУНТ.workers.dev`
   (виден на странице Worker'а, под именем).

---

## 4. Вписать всё в код сайта

Откройте `js/forms-config.js` и замените плейсхолдеры на реальные значения:

```js
window.LANMEI_FORMS_CONFIG = {
  emailjs: {
    publicKey: 'ваш ключ из шага 2.4',
    serviceId: 'ваш Service ID из шага 2.2',
    templateId: 'ваш Template ID из шага 2.3'
  },
  telegramWorkerUrl: 'https://lanmei-forms.ваш-аккаунт.workers.dev'
};
```

Пришлите мне готовые значения (или впишите сами и напишите, что готово) —
я закоммичу и запушу. До заполнения форма продолжает работать визуально
(показывает "успех"), но заявки никуда не уходят — сайт от этого не сломается.

---

## 5. Проверка

После заполнения конфига: откройте сайт, заполните бриф тестовыми данными,
отправьте. Проверьте, что письмо пришло на почту и сообщение — в Telegram.
Если что-то не пришло — откройте консоль браузера (F12 → Console), там будет
`console.warn` с причиной (EmailJS или Telegram-релей вернули ошибку).

---

## На будущее: вторая форма (обратный звонок и т.д.)

Worker уже универсальный — примет любые поля с любой формы, просто передайте
`formType` со своим названием. Клиентский код (как вызывать EmailJS/Worker)
можно скопировать из обработчика `#leadForm` в `js/main.js` под новую форму.
Для EmailJS понадобится либо отдельный шаблон под новые поля, либо один общий
шаблон с условными полями (`{{#if}}` не поддерживается — проще сделать новый
шаблон под каждую форму, это бесплатно).

(или добавьте) `https://funrw1234-del.github.io` на адрес нового домена и
переразверните Worker (Edit code → вставить → Deploy).
