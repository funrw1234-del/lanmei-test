# Настройка отправки заявок с сайта (почта + Telegram + Google Sheets)

На сайте три формы, все отправляют заявку в один и тот же Telegram-канал, на
одну и ту же почту и (опционально) строкой в Google-таблицу:
- **Квиз** (`#leadForm`, секция «Ответьте на 5 вопросов»)
- **Обратный звонок** (модалка, кнопка «Заказать звонок» в шапке)
- **Форма в подвале** («Остались вопросы?»)

Квизу и остальным двум формам нужны **разные** EmailJS-шаблоны — в письме от
звонка/подвала не должно быть пустых строк «Категория товара:», «Город
доставки:» и т.п., которых в этих формах просто нет.

## Архитектура (важно, если будете что-то менять)

И почта, и Telegram уходят **одним запросом с сайта в Cloudflare Worker**
(`cloudflare-worker/telegram-relay.js`) — сам Worker дальше стучится и в
Telegram Bot API, и в EmailJS REST API. Раньше почта уходила прямо из браузера
через EmailJS SDK отдельным запросом, а в Worker — только Telegram; из-за
этого блокировщик рекламы, ловящий домен `*.workers.dev` как «трекер», мог
зарубить именно Telegram-запрос, а письмо через `emailjs.com` уходило —
заявка терялась в одном из двух каналов незаметно. Теперь один запрос — либо
блокируется целиком, либо доходит и разносится на оба канала на стороне
Worker'а.

Из-за этого у EmailJS теперь появился **приватный ключ** (в дополнение к уже
знакомому публичному) — без него Worker не может слать письма от вашего
имени. Это единственное новое значение, которое нужно вписать.

## 2. EmailJS — приватный ключ (единственное, что нужно сделать сейчас)

1. Зайдите на [dashboard.emailjs.com](https://dashboard.emailjs.com) →
   **Account → API Keys** (или **Security**, если пункт называется иначе в
   вашем интерфейсе).
2. Скопируйте **Private Key** (не путать с уже знакомым Public Key).
3. Cloudflare Dashboard → Workers & Pages → **lanmei-forms** → **Settings →
   Variables and Secrets** → **Add** → имя переменной ровно
   `EMAILJS_PRIVATE_KEY`, тип **Secret**, значение — вставленный ключ → Save
   and deploy.

Service ID и Public Key уже вписаны прямо в код Worker'а (они не секретны —
и раньше были видны любому в исходниках сайта), их трогать не нужно.

Шаблоны (`template_hvldedk` — квиз, `template_cu9j7qh` — звонок/подвал) и их
ID в `js/forms-config.js` не менялись — какие поля должно печатать письмо
каждой формы, ищите в самих шаблонах на dashboard.emailjs.com. Если поменяете
набор полей формы (добавите/уберёте вопрос) — не забудьте поправить и
плейсхолдеры `{{...}}` в соответствующем шаблоне.

## 3. Google Sheets — опционально, если нужна выгрузка заявок в таблицу

1. Создайте новую Google-таблицу (например, «Lanmei — Заявки»).
2. В ней: **Расширения → Apps Script**.
3. Сотрите содержимое `Code.gs` и вставьте вместо него код из
   `google-sheets-apps-script.gs` (файл прислан отдельно) — сохраните.
4. **Развернуть → Новое развёртывание** → тип **«Веб-приложение»**:
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
5. При первом разворачивании Google покажет предупреждение о непроверенном
   приложении — это ваш собственный скрипт, жмите «Дополнительно» →
   «Перейти к проекту (небезопасно)» → разрешить доступ.
6. Скопируйте URL веб-приложения (заканчивается на `/exec`).
7. Cloudflare Dashboard → Workers & Pages → **lanmei-forms** → **Settings →
   Variables and Secrets** → **Add** → имя переменной ровно
   `GOOGLE_SHEETS_WEBHOOK_URL`, тип **Secret**, значение — скопированный URL →
   Save and deploy.

Без этого секрета Worker просто пропускает канал Sheets (заявки как и раньше
доходят по Telegram/почте) — это необязательный, а не основной канал.

Если позже поменяете набор полей в какой-то форме — Apps Script сам положит
любые незнакомые поля в колонку «Прочее (JSON)», ничего переделывать не
обязательно, но для красоты можно добавить новую колонку в `HEADERS` и в
`sheet.appendRow([...])`.

---

## 4. Cloudflare Worker — код уже обновлён, нужно задеплоить

`cloudflare-worker/telegram-relay.js` → Cloudflare Dashboard → **lanmei-forms**
→ **Edit code** → вставить актуальное содержимое файла из репозитория →
**Deploy**. Без этого шага сайт продолжит работать по старой схеме, пока код
на Worker'е не обновлён.

---

## 5. Проверка

Откройте сайт → кнопка «Заказать звонок» в шапке → заполните телефон →
отправьте. Проверьте письмо и Telegram-канал. Если что-то не дошло —
консоль браузера (F12 → Console) покажет `console.warn` с причиной, а в
ответе Worker'а (Cloudflare → lanmei-forms → Metrics/Logs) будет видно,
какой из каналов (`telegram`/`email`) вернул ошибку.

## На будущее: четвёртая форма

В `js/main.js` есть общая функция `submitLead(data, emailTemplateId)` — она
одним запросом уходит в Worker и возвращает `true`/`false`. Для новой формы:
своя HTML-разметка (по образцу модалки звонка), свой `formType`, свой
EmailJS-шаблон (если поля отличаются от уже существующих) и несколько строк
JS, вызывающих `submitLead(data, ваш_template_id)`.

переразверните Worker (Edit code → вставить → Deploy).
