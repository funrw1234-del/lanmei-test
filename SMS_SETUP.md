# Настройка SMS-подтверждения заявки клиенту

Код готов и уже лежит в `cloudflare-worker/telegram-relay.js` — тот же Worker,
что шлёт заявки в Telegram, теперь параллельно отправляет клиенту короткое
SMS: «Lanmei: заявка принята. Менеджер свяжется с вами в течение 2 часов.»

SMS отправляется, только если в поле «Телефон» удалось распознать настоящий
российский номер (11 цифр, начинается на 7/8). Для формы обратного звонка это
всегда так — там строгая маска. Для брифа поле называется «Телефон или
Telegram», и если человек ввёл ник — SMS просто не уйдёт, без ошибок.

Регистрацию сервиса и оплату может сделать только владелец аккаунта — я не
могу заводить сторонние аккаунты и вводить платёжные данные за вас.

---

## 1. Регистрация в SMS.ru

1. Зайдите на [sms.ru](https://sms.ru/) → «Регистрация», привяжите свой номер.
2. В личном кабинете: **Настройки → API** — там будет **ID для API**
   (строка вида `AABB1122-CCDD3344-EEFF5566-77889900`). Это и есть ваш
   `SMS_RU_API_ID`.
3. Пополните баланс на пробную сумму (100–200 ₽ хватит на десятки тестов —
   SMS в РФ стоит ориентировочно 2–3 ₽ за штуку).

### Имя отправителя (необязательно, можно пропустить на старте)

Без регистрации имени SMS будут приходить с общего короткого номера SMS.ru —
это нормально работает, просто не так красиво, как подпись «Lanmei» вместо
номера. Если захотите брендированного отправителя — в кабинете **Имена
отправителей → Добавить**, нужны реквизиты юрлица, модерация занимает
1–3 рабочих дня. Можно сделать позже, это не блокирует запуск.

---

## 2. Cloudflare Worker — добавить секрет

1. [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages →
   `lanmei-forms` (тот же Worker, что уже шлёт в Telegram).
2. **Settings → Variables and Secrets → Add** →
   - Name: `SMS_RU_API_ID`
   - Value: ID из шага 1.2
   - Type: **Secret** (не обычная переменная — так он не будет виден в коде).
3. **Deployments** → откройте текущий код (**Edit code**) → вставьте
   актуальное содержимое `cloudflare-worker/telegram-relay.js` из репозитория
   → **Deploy**.

   ⚠️ Как и с CORS-фильтром раньше: этот Worker не подтягивает код из GitHub
   автоматически — код нужно вставлять вручную при каждом изменении файла.

---

## 3. Проверка

Оставьте тестовую заявку на сайте (форма «Рассчитать доставку» или «Заказать
звонок») со своим настоящим номером. В течение нескольких секунд должно
прийти SMS. Если не пришло:

- Проверьте баланс в личном кабинете SMS.ru.
- Откройте ответ Worker'а — в JSON будет поле `sms` с тем, что вернул SMS.ru
  (`{"status":"ERROR","status_code":...}` — код ошибки объясняет причину:
  неверный `api_id`, нет денег на балансе, невалидный номер и т.д.).

---

## Стоимость

SMS не бесплатны — каждая реальная заявка с валидным номером телефона будет
стоить ~2–3 ₽. При обычном потоке заявок это копейки, но если ожидаете резкий
рост трафика — стоит держать это в уме при пополнении баланса.
